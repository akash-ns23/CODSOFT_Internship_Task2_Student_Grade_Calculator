# Student Grade Calculator

## Description
This is a Java console application that calculates a student's total marks, average percentage and grade based on the marks entered for each subject.

## Features
- Accepts marks for multiple subjects
- Calculates total marks
- Calculates average percentage
- Assigns grades based on average percentage
- Displays the final result

## Grade Criteria
- A+ : 90% and above
- A  : 80% - 89%
- B  : 70% - 79%
- C  : 60% - 69%
- D  : 50% - 59%
- F  : Below 50%

## Technologies Used
- Java
- Scanner Class

## How to Run

1. Compile the program:
```
javac GradeCalculator.java
```

2. Run the program:
```
java GradeCalculator
```
